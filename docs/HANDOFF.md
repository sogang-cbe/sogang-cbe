## 정한 것 — 게시판 상단 고정(공지) 기능 제거 (2026-10-08)

옛 사이트에서 '공지'로 올라와 있던 글이 1,779건 중 356건(학사공지만 733건 중 약 230건)이라
고정글이 목록 앞부분을 통째로 차지했다. 책임자 판단으로 **상단 고정 기능 자체를 없앴다.**
목록은 날짜순 하나로만 정렬한다.

- 정렬에서 `is_pinned` 제거(`lib/data.ts` 목록·홈 소식), 목록 No. 칸은 일련번호
- 홈 소식의 '중요' 칩, 관리자 목록의 PIN 표시, 입력 폼의 '상단 고정' 체크박스 제거
- `posts.is_pinned` 칼럼은 **남겨 두었다**(값도 그대로). 읽는 코드가 없으므로 동작에 영향 없고,
  되살릴 일이 생기면 정렬과 표시만 되돌리면 된다.
