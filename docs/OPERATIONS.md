# 운영 가이드 (화공생명공학과 홈페이지)

> 작업 규칙은 루트 `CLAUDE.md`, 최근 작업과 미결 사항은 `docs/HANDOFF.md`.
> **비밀번호·API 키는 이 저장소(공개)에 절대 적지 않는다** — 학과 구글드라이브의 계정 문서에 보관한다.

## 1. 구성

```
방문자 → https://sogang-cbe.vercel.app   (공식 도메인 연결 예정: chemeng.sogang.ac.kr)
           │
           ▼
        Vercel  ──  홈페이지 실행 (Next.js 14, 이 저장소 main 브랜치 자동 배포)
           │
           ├── Supabase ── 게시글·교수진·고정페이지·예약·구성원·장비 (Postgres + 인증)
           └── Cloudflare R2 ── 첨부·이미지 공개 저장(sogang-cbe-media) / 백업(sogang-cbe-backup)
```

모든 서비스는 학과 공용 구글 계정 `chemeng.sogang@gmail.com` 으로 묶여 있다. 이 계정의 비밀번호와 2단계 인증을 넘기면 인수인계의 대부분이 끝난다.

| 하고 싶은 일 | 어디서 |

| 고정 페이지 문구 수정 | `/adm/pages` (코드보다 우선 적용된다) |
| 학과회의실 예약 처리 | `/adm/reservations` |

| 대학원생·교수 로그인 승인 | `/adm/members` |

| 백업 확인·휴지통 복구 | `/adm/backup` |

## 3. 구성원 로그인

1. 학생·교수가 `/ko/equipment`에서 "서강대 구글 계정으로 로그인"을 누른다.
2. `@sogang.ac.kr` 계정만 통과하고, `members` 테이블에 `pending`으로 등록된다.
3. 행정실이 `/adm/members`에서 **대학원생 / 교수 / 행정실** 중 하나로 바꾼다.
4. 승인된 사람만 공용장비와 자료실을 볼 수 있다. 졸업·퇴직자는 `승인 대기`나 `거절`로 되돌린다.

## 4. 공용장비 운영

- 사용료는 없다. 예약 → QR 체크인 → 체크아웃이 전부다.
- 장비마다 `담당자 승인 후 확정`을 켜면 신청이 대기 상태로 들어온다. 끄면 바로 확정된다.
- QR 주소는 `/adm/equipment` 표에 그대로 나온다. 무료 QR 생성기로 코드를 만들어 장비 앞에 붙인다. 토큰이 들어 있어 다른 장비 QR로는 체크인되지 않는다.
- 같은 장비·같은 시간에 두 예약이 들어가지 않도록 DB에서 막는다. 예약이 겹치면 "그 시간에는 이미 예약이 있습니다"가 뜬다.
- 체크인 없이 예약 시간이 지난 건은 `/adm/equipment` 최근 기록에서 **노쇼 표시**를 누른다. 노쇼가 쌓이는 사람은 학과 규칙에 따라 조치한다(규칙은 운영하면서 정한다).

## 5. 사용량과 요금 (모두 무료 범위 목표)

| 서비스 | 요금제 | 주의 |
|---|---|---|
| Vercel | Hobby(무료) | 엣지 요청·함수 호출 월 100만, Active CPU 월 4시간. 넘으면 다음 주기까지 사이트가 멈춘다. 새 동적 경로에 `generateStaticParams`를 꼭 넣을 것 |
| Supabase | Free | DB 500MB · 전송 5GB/월. 게시글 본문·첨부를 R2에 두는 이유 |
| Cloudflare R2 | Free | 저장 10GB · 송신 무료. 옛 파일은 "실제로 쓰이는 것만" 올려 약 4GB |
| Resend(알림 메일) | Free | 월 3,000통. 키가 없으면 신청은 접수되고 메일만 생략된다 |

## 6. 문제가 생기면

- **사이트가 안 열린다** → Vercel 대시보드에서 배포 상태와 사용량 확인. 한도 초과면 다음 주기까지 기다리거나 일시적으로 Pro.
- **로그인이 안 된다** → Supabase Authentication › Providers › Google 설정과 Redirect URL(`/auth/callback`) 확인.
- **사진이 안 보인다** → `NEXT_PUBLIC_MEDIA_BASE` 환경변수와 R2 버킷 공개 설정 확인.
- **글을 지웠다** → `/adm/backup` 휴지통에서 30일 안에 복구.
- **표나 문구가 틀렸다** → `/adm/pages`에서 고치면 코드 수정 없이 바로 반영된다.
